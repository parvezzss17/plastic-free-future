# Plastic Free Future

A responsive environmental awareness website designed to educate users about plastic pollution, different plastic categories, and sustainable alternatives.

## Live Demo

https://parvezzss17.github.io/plastic-free-future/

## Features

* Multi-page website
* Information about PET, HDPE, PVC, LDPE, PP, and PS plastics
* Environmental awareness content
* Responsive design for desktop and mobile devices
* Educational resources promoting sustainable living

## Technologies Used

* HTML5
* CSS3

## Project Structure

* index.html
* style.css
* pet.html
* hdpe.html
* pvc.html
* ldpe.html
* pp.html
* ps.html
* images/

## Purpose

This project was developed as part of a community service initiative to raise awareness about plastic pollution and encourage environmentally responsible practices.
